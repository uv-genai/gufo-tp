# Gufo-TP v0.28.1 fixes — November 6, 2026

Release tag: `tp2-rdma-fixes-v0.28.1-2026-11-06`.
Changes since `tp2-rdma-merge-v0.28.1-2026-11-04`, on the existing upstream
v0.28.1 base. This is a Linux TP2 source release; `version.txt` remains 0.28.1.

## Fixes

- **Reasoning and cache controls on both ranks.** Reasoning budgets and model
  reasoning metadata now reach the worker. Chat and raw Completions honor
  `cache_prompt: false`; `cache_persist: false` prevents either rank from
  persisting that request while retaining RAM reuse.
- **Correct paired Q8 expert prefill.** The gate/up kernel now decodes both
  signed Q8 byte halves with their scale and handles 64-element K stages.
  The old path could produce zero projections during larger prefills.
  The numerical cache epoch rejects states computed by that old path.
- **Current TP2 executor regression coverage.** The executor test follows the
  current runner interface and runs in the Linux PR suite. Mirrored in-pass
  rollback remains explicitly unsupported; cancellation occurs between calls.
- **Load metadata-only Q4 shards.** The complete first shard of the current
  four-file UD-Q4_K_XL set is only 10,946,618 bytes and has zero tensors.
  The reader no longer requires tensor padding on such a shard. Truncated
  metadata and invalid weight extents remain rejected. No model file edits
  or replacement downloads are required when publisher checksums match.

## Performance observations and known limits

The user reported about **45 tok/s generation** and **up to 1,550 tok/s prefill**,
with Q8 prefill faster than Q4 in their interactive workload. These observations
are not a matched Q4/Q8 benchmark and do not replace the historical tables.

The controlled Q8 timing study compared `78d8a4bf` with `c1e4cc38`, before the
final metadata-reader fix. **58/66** per-request phase comparisons were within
5% and 10 ms; **8 MTP** comparisons remain inconclusive after repeats and
unchanged-main controls. No qualified speedup or established timing regression
is claimed. [Measurements](../models/qwen3.8-flash-next/BENCHMARKS.md#q8-regression-controls-november-6-2026).

Sparse attention retains its existing numerical envelope; the full-model split
probe still has a maximum logit difference of 0.698152. This release does not
claim byte-identical sparse logits across different chunk layouts.

One client displayed `Error generating response body`. Regeneration succeeded,
both ranks stayed alive, and the inspected Gufo/proxy logs did not establish a
cause. This is retained as an unreproduced observation, not a fixed stream bug.
