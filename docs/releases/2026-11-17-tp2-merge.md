# Gufo-TP v0.34.0 upstream integration — November 17, 2026

Release tag: `tp2-rdma-merge-v0.34.0-2026-11-17`.
This Linux TP2 source release integrates upstream v0.34.0 since
`tp2-rdma-merge-v0.33.0-2026-11-11`. It keeps all earlier TP2 fixes and gates.

## Changes

- Upstream v0.34.0 ([#36](https://github.com/uv-genai/gufo-tp/pull/36)):
  - Fused batched FFN HC mixing with Q8 activation reuse.
  - MTP backoff recovery after jointly planned batches.
  - HTTP and multipart parsing in Rust.
  - Prompt-state admission.
  - Live-frontier prompt alignment for re-tokenized answers on one host.
  - Disk cache admission fixes.
  - Deprecated draft flags.
  - Rust audio decoding.
  - Extension source revisions.
  - Source extension API **0.3.2**, from upstream's 0.3 baseline.
- **TP2 fix:** upstream's live-frontier alignment assumed a component cache,
  but the mirrored TP2 runner does not construct one. The pool now keeps the
  tokenized prompt when no component cache exists. This removes a latent
  rank-0 null dereference. A regression test segfaults without the guard.
- The fused HC and Q8 paths change no collective order, count or size. TP2
  keeps component-cache restore, draft subsets, prompt copies, deferred
  residuals, dynamic YaRN re-rotation, layer yields and decode-overlap
  calibration disabled.
- Build prerequisites: libopus replaces libsndfile and libsoxr.
- Hosted GitHub CI is disabled on this fork. Every check runs locally before a
  push ([#37](https://github.com/uv-genai/gufo-tp/pull/37)).

Upstream commits after the v0.34.0 tag are excluded, including the Q4_K MTP
head-prefix draft path.

## Known limits

Timing is **inconclusive and unqualified**. Short-code prefill was flagged at
first. In the main/candidate/main repeat, Q8 does not reproduce the flag. Q4
remains flagged against one of two main controls, while unchanged main itself
spans 168–198 ms. No regression is confirmed and no speedup is claimed. The
single pp2048/tg128 rates (Q4 decode 38.3 → 42.9 tok/s) are observations, not
a qualified gain.

Live-frontier alignment does not apply under TP2. The sparse-prefill numerical
envelope and the 0.698152 split-probe logit difference remain. Full-depth
context, Q8 images, other model families and Windows were not requalified. The
earlier client `Error generating response body` remains unreproduced.
